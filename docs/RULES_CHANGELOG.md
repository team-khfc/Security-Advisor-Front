## 유지한 사항

- 재검토 범위, 같은 서류 유형 재신청, 유형별 확정 주체, 방화벽 기간 등 미결 정책은 임의 확정하지 않음.
- CODING_STYLE v0.7, SECURE_CODING v1.5, design v3.1은 제공 ZIP과 바이트 단위 동일.
- 과거 결정·관측·개정 이력은 추적용으로 보존. 공개용 문서에 개인 연락처를 추가하지 않음.
- BACKLOG와 촬영 대본은 원본 ZIP에 없어 포함·수정하지 않음.

## 적용 범위

이 파일 묶음은 수정본 산출물이다. 원본 ZIP, GitHub·공공 GitLab, Docker, 실제 계정·신청 데이터는 변경하지 않았다. 저장소 반영 시 9종 규칙과 docs/SOURCE_PROVENANCE.md를 함께 반영하고 포함된 검사기를 실행한다. 기존 출처 기록의 필요한 과거 이력은 보존한다. 기능 소스 스냅샷의 hashes는 문서 동기화 목적으로 임의 갱신하지 않는다.

## 저장소 반영 추가 정리

사용자의 후속 요청에 따라 GitHub·공공 GitLab의 Back·Front·통합 저장소에 규칙과 docs 가이드를 함께 반영한다. 위 ZIP 생성 시점의 “원격 미반영”은 과거 작업 범위다. AGENTS v1.22는 0장 실행 설명을 2장과 맞추고 PROJECT_CONTEXT v3.11은 기준표·동기화 현황을 갱신한다. 본 변경은 문서·규칙만으로 기존 소스 스냅샷과 Docker 실행 데이터는 유지한다.
