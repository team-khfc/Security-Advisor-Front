# 인터뷰 UI 실제 화면 검증

2026-11-11 (한국 시간). 기준 main: `fe5d006`, 수정 이슈: #71.
디자인 기준: prototype-soo `563dd7e76aeeb4fe63f010bec9cd1f9bac16d5dc` 및 MERGE_NOTES.md.

## 재현 및 수정

3001 도커의 합성 사업 141에서 인터뷰 답변 또는 수집 정보 개별 답변을 저장하면,
서버 저장 결과가 캐시에 반영된 직후 아직 저장 요청이 완료되지 않은 사이에
자신이 저장한 수정본을 외부 수정으로 판단해 충돌 안내가 잠시 노출됐다.

저장 처리 중에는 충돌 안내를 표시하지 않는다. 수정본 비교, 저장 차단,
실패 시 입력 보존 및 최신본 확인 후 재시도 절차는 그대로 유지한다.
지연된 저장 중 캐시 갱신 및 실패 후 실제 충돌 표시를 자동 검사로 확인했다.

파일은 실제 정보가 없는 합성 TXT를 사용했다. 실제 장비 변경, 제출·확정은 수행하지 않았다.
브라우저의 날짜 자동 채우기는 변경 이벤트를 반영하지 않아 실제 키보드 입력으로 검증했다.

## 실제 모델의 제한

3001의 기존 모델 연결 시험은 성공했지만 문서 요약 요청은 공급자 HTTP 402로 실패했다.
현재 계정 잔액으로 설정된 최대 4,096토큰 요청을 처리할 수 없다는 응답을 확인했다.
잔액·키·모델 설정은 변경하지 않았다. 따라서 3001에서 실제 모델 문서 분석 성공은
미검증이며, 성공 UI는 별도 3012의 합성 응답으로 검증했다. 운영 성공 검증을 위해서는
모델 계정 잔액 또는 최대 출력 토큰 정책을 관리자가 조정한 후 재시험해야 한다.
