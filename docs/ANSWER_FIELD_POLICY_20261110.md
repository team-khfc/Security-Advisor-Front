# 답변 항목 권한·형식 화면 검증

2026-11-10 · Front #64 / Back #23

작성자는 자기 역할 항목을 수정한다. 담당자는 신청자의 AI 답변·재검토 항목을 확인할 수 있으나
다른 담당 분야의 항목을 편집·확인하는 UI는 제공하지 않는다. 최종 권한은 서버가 검사한다.

인터뷰·전체 답변 편집·저장 훅·모의 API에서 게시본 형식을 검사한다. 잘못된 입력은 오류와 함께 보존한다.
숫자는 십진수, 예/아니요는 `true`/`false`/`예`/`아니요`, 기간은 실제 날짜와 시작·종료 순서를 검사한다.
기존 종료일 생략·상시 표현은 유지한다. 형식 검사는 IP/포트 같은 TEXT 항목에 임의 제약을 추가하지 않는다.

담당자의 여러 필드 저장은 병렬 PUT 대신 `PATCH /api/reviews/{id}/answers` 한 번으로 처리한다.
기존 방식은 같은 협의 revision 갱신이 충돌해 일부만 저장될 수 있었다. 새 API는 전체 성공/실패한다.
답변 저장과 AI 확인은 기존처럼 분리하며 출처를 보존한다. 백엔드 PR을 먼저 배포해야 한다.

## 검증

- `npm run format`, `npm run check`: 타입·린트·325개 테스트·문서 버전 검사 통과.
- 다른 분야 AI/재검토 확인 UI 차단, 잘못된 기간 저장 호출 차단·입력 보존 회귀 테스트 추가.
- Docker 3014/8094에서 합성 신청자·INFRA·SECURITY 계정으로 실제 화면 검증.
- 신청자: 잘못된 기간 거부→정상 저장, 선택형 저장, AI 미확정 적용→확인.
- INFRA: 세 항목 일괄 저장 성공, SECURITY 항목 편집 UI 없음.
- SECURITY: 숫자 오류 거부→정상 저장, INFRA 항목 편집/확인 UI 없음, 신청자 AI 답변 확인 가능.
- 도커 API 검증 21개 통과. AI는 합성 응답으로 경계·형식·출처 처리 검증.
- 시안 기준: prototype-soo `563dd7e76aeeb4fe63f010bec9cd1f9bac16d5dc`, MERGE_NOTES 확인. 기존 화면 구조·토큰을 유지한 권한·오류 안내 수정.
- 기존 3001 환경은 유지하고 별도 검증용 3014에 수정본을 실행했다.
