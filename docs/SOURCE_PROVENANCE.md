# 규칙 문서 원본과 공개본 출처

## 공개본 변환 범위

이 저장소 루트의 규칙 문서 8종은 사용자가 이번 작업에 첨부한 최신 원본을 기준으로 동기화했다. **팀 실명은 원본에 정의된 역할명으로, 팀원의 개인 이메일은 `비공개`로 치환한 공개본**이다. 역할명 치환으로 중복되는 역할 표현과 조사는 필요한 범위에서만 정리했다. 원본의 업무 규칙, 권한, 일정, 절차, 명령, 머리말의 기준 버전·개정일은 개정하지 않았다. 공개본은 개인정보가 포함된 원본과 바이트 단위로 같지 않으므로, 아래에 원본과 공개본의 SHA-256을 각각 기록한다.

공개본 변환은 새로운 업무 규칙 버전을 정한 작업이 아니다. 기준 버전은 `PROJECT_CONTEXT.md` 5장 표를 유지하며, 공개 저장소에서 사본을 동기화할 때에는 개인정보가 포함된 원본 대신 이 공개본과 변환 기록을 함께 사용한다. 다른 저장소의 문서를 이번 작업에서 변경하거나 동기화 완료로 간주하지 않았다.

`PROJECT_RULES.md`에 있는 대회 운영기관의 공용 문의 메일·대표 문의 전화는 개인 연락처가 아닌 공개 기관 연락처이므로 원문을 유지했다. 운영 기관 예시, 팀 역할과 부서, 참고 자료·공식 출처 URL도 원문 그대로 유지했다.

## 확인 방법과 한계

`python3 tools/check_doc_versions.py`는 기준 버전 표와 9종 문서의 머리말, 정해진 사본 경로, 위 8종 공개본의 해시, 규칙 문서에 남은 이메일·전화 형식을 검사한다. 허용된 공용 문의 연락처와 문서용 예시 도메인은 개인정보 검사에서 구분한다. 이 검사는 일반적인 개인정보 의미 판별 도구가 아니며 모든 종류의 비밀값을 탐지한다고 보장하지 않는다. 공개본 해시 검증은 이번에 확인한 비식별 문서가 이후 조용히 바뀌는 것을 탐지하기 위한 것이다.

`claude/INSTRUCTIONS.md`는 사용자가 대화에 직접 제공한 v1.13 요약 지침에서 작성하므로 첨부 8종의 원본 해시 표와 구분한다. 해당 파일도 버전·개정일·단일 경로 점검 대상이다.

`design.md` 원문에 남아 있는 이전 시안 경로·커밋과 미해결 시각 항목은 원본의 기록이며, 이 동기화 작업에서 임의로 수정하지 않았다. 실제 화면 구현이 참고한 최신 `prototype-soo` 커밋과 업무 규칙 우선 적용 사항은 프론트 개발 문서·PR 설명에 별도로 기록한다.
